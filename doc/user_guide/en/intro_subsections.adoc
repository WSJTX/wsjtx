=== Documentation Conventions

This guide includes many screen shots to illustrate user settings and
program features.  Keep in mind that _WSJT-X_ is a multi-platform
application; the detailed appearance of windows and user controls
will be different in Windows, Linux, or macOS environments.
The underlying functionality is the same on all operating systems,
however.  Where desirable we call special attention to important
platform differences.

Most people access the _WSJT-X User Guide_ primarily through a
browser. Use the browser's search function, generally invoked from the
keyboard with the keys CTRL+F, to search the guide for help on a
particular topic or keyword.

The names of _WSJT-X_ windows, menus, and on-screen controls are
displayed in this manual in boldface type, as in *Wide Graph*.  File
names and information entered via keyboard is shown in a monospace
font, for example `all.txt`.


In this manual the following icons call attention to particular types
of information:

TIP: *Tips* on program features or capabilities that might otherwise
be overlooked. 

NOTE: *Notes* containing information that may be of interest to
particular classes of users.

IMPORTANT: *Warnings* about usage that could lead to undesired
consequences.

=== Other Languages

The _WSJT-X_ user interface (UI) is available in many languages.
Choose the interface language in *Settings -> General -> Display* using
*Language (requires restart)*, then restart _WSJT-X_ to apply the choice.
*System default*, the initial setting, automatically uses a translation
matching the computer's system language when available. Choose *English*
to use the original English interface regardless of the system language.
The choice is shared across named station configurations within the same
instance; separate instances started with `--rig-name` retain their own
language preferences.

The `--language` command line option overrides the saved preference for
that launch without changing it. To recover an English interface, start
_WSJT-X_ with `wsjtx --language en`. On Windows, the option can also be
appended to the executable path in a shortcut's *Target* field.

For example, to start _WSJT-X_ with its user interface in Spanish or
Japanese, start a command-prompt window and enter one of these commands:

`wsjtx --language es`

`wsjtx --language ja`

=== Contributing

*WSJT* is an open-source project hosted at {devrepo}. If you have
programming or documentation skills or would like to contribute to the
project in other ways, please make your interests known to the
development team. You can submit bug reports, suggestions for new
features, and explicit pull requests at the {devrepo} site. We
especially encourage those with translation skills to volunteer their
help, either for this _User Guide_ or for the program's user
interface.
