*_QMAP_* is a companion program installed automatically alongside
_WSJT-X_ and running cooperatively with it to provide wideband,
single-polarization reception of Q65 signals. While _WSJT-X_ decodes a
passband up to 5 kHz wide and a single speficied T/R sequence length,
_QMAP_ monitors an entire 90 kHz sub-band and automatically decodes
both 30 s and 60 s sequences. The combination makes a very convenient
setup for EME, especially on the UHF and microwave bands. You can see
and decode all the EME activity in the sub-band while conducting your
own QSOs with _WSJT-X_.

To gain some familiarity with _QMAP_, start the program and open its
*Vertical Waterfall* from the *View* menu. Resize and position the
windows for convenience, perhaps as in the screen shot below. Set
*Span* to 90 kHz on the *Horizontal Waterfall*. Then use *File | Open*
to select the sample file ...\save\samples\QMAP\221112_0438.qm.

_QMAP_ decodes the file's full 90 kHz sub-band and for each signal
displays the *UTC* time, received frequency *Frx*, and suggested
calling frequency *Fsked*, time offset *DT*, SNR *dB*, submode
*Q65-x*, and decoded message. Transmissions in a 30 s submode are
highlighted in yellow. Callsigns of transmitting stations are
displayed on the waterfall windows, close to the received frequencies.

image::qmap_all.png[align="center",alt="QMAP main window"]

If _WSJT-X_ is also active and in Q65 mode, information from _QMAP_
decodes will appear in the _WSJT-X_ *Active Stations* window sorted
by received frequency:

image::active_stations_QMAP.png[align="center",width=50%,alt="Active Stations"]

Click a callsign on either of _QMAP_'s waterfalls, or in the *Active
Stations* window, to set up a QSO with that station in _WSJT-X_.
_WSJT-X_ will generate the appropriate messages and set the dial
frequency to that station's suggested calling frequency,
*Fsked*. Double-clicking will also activate *Enable Tx* so you can
call the station right away.

The symbol *#* at the right edge of *Active Stations* marks a callsign
not yet present in `wsjtx.log`. This is a convenience for tracking EME
initials or contest QSOs. An asterisk +*+ marks a station whose most
recent transmission contains `CQ`, `RR73`, or `73`, so the sender is
presumably ready to start another QSO. Use the *Wanted only* and *CQ
only* checkboxes and *Max Age* spinner to narrow the list of stations
as desired. With focus on the _WSJT-X_ main window you can press
*Alt+A* to clear *Active Stations* and start over.

Ideas that might be used later, elsewhere:
For live operation, you should first set *Doppler tracking* on the
*Astronomical Data* window and select *Constant frequency on Moon* for
on the, so this frequency continues to track the Moon correctly for
the rest of the QSO.

TIP: _QMAP_ can also record what it receives, for later review: select
*Save | Save decoded* or *Save | Save all* on its main window. Saved
files -- compact `*.qm` files, like the one you just opened, or raw
`*.iq` data -- go to the *Save Directory* set on the *Station* tab.
*File | Open next in directory* (*Shift+F6*) steps through every saved
file in a directory in turn, as if you were receiving them live.

For live reception, _QMAP_ needs a wideband SDR front end, normally
provided by _Linrad_ (by SM5BSZ), and some initial setup on the *File
| Settings...* dialog -- entering *My Call* and *My Grid*, and
correcting for any frequency offset in your receiving chain with the
*Fcal (Hz)* and *Fadd (MHz)* fields. That hardware setup is beyond
this tutorial; instead, try _QMAP_ here with a saved file, the same
way you've already done for other modes.
