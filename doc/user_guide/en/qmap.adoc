*_QMAP_* is a companion program installed automatically alongside
_WSJT-X_ and running cooperatively to provide wideband,
single-polarization reception of Q65 signals. _QMAP_ automatically
decodes both 30 s and 60 s sequence lengths. While _WSJT-X_ decodes a
passband up to 5 kHz wide, _QMAP_ monitors an entire 90 kHz
sub-band. The combination makes a very convenient setup for EME,
especially on UHF and microwave bands. You can see and decode all the
EME activity in the sub-band while conducting your own QSOs with
_WSJT-X_.

Start _QMAP_, open the Vertical Waterfall from the View menu, and
resize and position the windows conveniently -- perhaps something like
the screen shot below. Set *Span* to 60 kHz on the Horizontal
Waterfall. Then use *File | Open* to select the file
`...\save\samples\QMAP\221112_0438.qm` which you will have downloaded
already from the _WSJT-X_ *Help | Download samples* menu item.

image::qmap_all.png[align="center",alt="QMAP main window"]

_QMAP_ will decode the file's full 90 kHz sub-band, for each decode
showing the time, received frequency *Frx*, suggested calling
frequency *Fsked*, *DT*, *dB*, the Q65 submode, and message text. The
decoded callsigns are displayed directly on the waterfalls.

If you have _WSJT-X_ also running and in Q65 mode, information on
_QMAP_ decodes will appear in its *Active Stations* window, sorted by
received frequency:

image::active_stations_QMAP.png[align="center",width=50%,alt="Active Stations, fed by QMAP"]

Rows decoded in a 30 s Q65 submode are highlighted in yellow, to
distinguish them from 60 s decodes at a glance. The symbol `#` after
*Age* marks a station not yet present in `wsjtx.log`, and an asterisk
`*` marks one whose most recent transmission contained `CQ`, `RR73`,
or `73`, and whose operator is presumably ready to start another
QSO. Use the *Wanted only* and *CQ only* checkboxes, and the *Max Age*
spinner, to narrow the list as desired. You can clear it and start
over bt pressing *Alt+A* with focus on the _WSJT-X_ main window.
Click a callsign on either of _QMAP_'s waterfalls to set up a QSO with
that station in _WSJT-X_; double-clicking will also arm *Enable Tx* to
call the station right away. _WSJT-X_ will generate the appropriate
messages and set the dial frequency to that station's suggested
calling frequency, *Fsked*.

Ideas that might be used later, elsewhere:
For live operation, you should first set *Doppler tracking* on the
*Astronomical Data* window and select *Constant frequency on Moon* for
on the, so this frequency continues to track the Moon correctly for
the rest of the QSO.

TIP: _QMAP_ can also record what it receives, for later review: select
*Save | Save decoded* or *Save | Save all* on its main window. Saved
files -- compact `*.qm` files, like the one you just opened, or raw
`*.iq` data -- go to the *Save Directory* set on the *Station* tab.
*File | Open next in directory* (*Shift+F6*) steps through every saved
file in a directory in turn, as if you were receiving them live.

For live reception, _QMAP_ needs a wideband SDR front end, normally
provided by _Linrad_ (by SM5BSZ), and some initial setup on the *File
| Settings...* dialog -- entering *My Call* and *My Grid*, and
correcting for any frequency offset in your receiving chain with the
*Fcal (Hz)* and *Fadd (MHz)* fields. That hardware setup is beyond
this tutorial; instead, try _QMAP_ here with a saved file, the same
way you've already done for other modes.
