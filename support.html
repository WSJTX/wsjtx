Questions & discussion

For setup questions, operating help, and general conversation, use GitHub Discussions — the official home for community Q&A. It’s the best place to get help from the developers and fellow operators, and it’s where conversation that once lived on the mailing lists now happens, in the open and alongside the code.

Reporting a bug

Found a reproducible problem? Open an issue at github.com/WSJTX/wsjtx/issues. A useful bug report includes at least:

  • Program version
  • Operating system
  • A concise description of the problem
  • The exact sequence of steps required to reproduce it

Code contributions are welcome too — send a Pull Request on GitHub.

Community resources

Official help and discussion now live on GitHub. The legacy channels below remain readable and are still monitored by members of the team, but we encourage you to bring new questions to Discussions, so answers stay with the official project:

  • WSJTX users’ forum (groups.io): wsjtx.groups.io
  • wsjt-devel mailing list: wsjt-devel@lists.sourceforge.net
