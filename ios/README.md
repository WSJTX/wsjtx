# WSJT-X for iPhone

A native iOS/SwiftUI port of [WSJT-X](https://wsjt.sourceforge.io/), supporting weak-signal amateur
radio digital modes: **FT8**, **FT4**, **JT65**, **JT9**, **WSPR**, and **Q65**.

## Architecture

```
ios/
└── WSJTX-iOS/
    └── Sources/WSJTX/
        ├── App/          — SwiftUI entry point, AppDelegate
        ├── Models/       — RadioMode, DecodedMessage, QSORecord, AppSettings
        ├── Audio/        — AVFoundation capture/playback, AudioEngine
        ├── DSP/          — Accelerate-based FFT, waterfall data model
        ├── Decoder/      — FT8/FT4 protocol constants, LDPC decoder, message parser
        ├── Encoder/      — FT8/FT4 symbol encoder, audio waveform synthesis
        ├── Network/      — UDP rig-control (WSJT-X compatible protocol), PSKReporter
        ├── Views/        — SwiftUI screens (waterfall, messages, logbook, settings)
        └── Utilities/    — Grid-locator math, UTC clock, callsign helpers
```

## Requirements

- Xcode 15+
- iOS 17+
- Swift 5.9+
- A **licensed amateur radio operator** callsign is required for transmitting.
- An SDR or transceiver with audio interface (e.g., Icom RS-BA1, Yaesu SCU-LAN10, or a
  hardware audio adapter).

## Setup in Xcode

1. `File › Add Package Dependencies…` — this repo is a Swift Package.
2. Select the `WSJTX-iOS` target and link it to your app target.
3. Or open `WSJTX-iOS.xcworkspace` (generated by `xcodegen` if you add a `project.yml`).

Alternatively, create a new **iOS App** project in Xcode and drag the `Sources/WSJTX` folder in.

## Key Libraries Used

| Framework | Purpose |
|---|---|
| AVFoundation | Real-time audio capture & playback |
| Accelerate | vDSP FFT, vector operations |
| Network | UDP socket for rig control |
| CoreLocation | GPS-derived grid locator |
| SwiftUI | UI framework |
